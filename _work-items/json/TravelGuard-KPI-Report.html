1. Headline

21 days into the schema rollout, every primary KPI is moving in the right direction. The citation metrics — the numbers most directly tied to schema work — led the way.

Own-domain citations are up +58.9% (185 → 294), citation share doubled (1% → 2%), domain coverage is up +5pp (8% → 13%), the brand-coverage trend reversed from −1 to +1, and the gap to Seven Corners (#1) narrowed by 40 mentions — the closest in this dataset.

Schema is plausibly contributing, but the rollout is too recent for confident attribution — competitor decay, content quality, and LLM index churn are also at work. The Jun 23 checkpoint will tell us how much of this trajectory holds.

7. What's attributable to schema vs. noise

The honest read: probably some, but not all.

  • Site-wide bundle (Organization + WebSite) has been live longest and has had the most time to propagate. Bing/ChatGPT search likely sees it; Google AI Overviews may not yet.
  • Per-page schemas (Plan, FAQ, Service, Article) were finalized in the repo only in the last ~6 days before the checkpoint — too recent for LLM indexes to have refreshed against them.
  • Competitor decay accounts for some of the relative gain — when Allianz and World Nomads lose ground, Travel Guard rises by default.
  • Content quality + index churn — the pre-existing-conditions +79% jump likely predates the schema being live, so most of that movement is content + LLM index updates, not yet schema.

What to watch at Jun 23: if citation share keeps climbing 2% → 3%, that's the strongest week-5 schema signal available. If the per-page-schema'd pages (CFAR, pre-existing, plans) keep gaining disproportionately, that supports the schema-first hypothesis. A plateau would mean the jump was mostly competitor weakness + seasonality.

How to update this report at each checkpoint

  1. Charts: in the <script> at the bottom of this file, append one object — { date:'2026-06-23', value: N, label:'Jun 23' } — to each metric's data array in SERIES. The charts redraw automatically; nothing else in the markup changes.
  2. Milestones: add deploy events to the MILESTONES array (date + label). They appear as numbered vertical lines once inside a chart's date range.
  3. Tables: update the "Current" / "Δ" cells in the §3 scorecard tables (and §5 per-prompt) to the new pull's values, and add a row to the checkpoint log above.
  4. Narrative: refresh the §1 headline callout and §7 attribution read with the new window's story.
  5. All numbers must come from the Otterly / GSC / Adobe Analytics pull — never estimated. Same content-fidelity rule as the JSON-LD work.
